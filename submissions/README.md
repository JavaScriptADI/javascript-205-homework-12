# Submissions

Each student creates **one folder here**, named after their GitHub username (`submissions/<your-username>/`).

```text
submissions/
├── README.md
└── nino-b/
    ├── index.html
    ├── style.css
    ├── api.js
    ├── app.js
    ├── check_1.js
    ├── bug_a/
    │   ├── index.html
    │   ├── style.css
    │   └── app.js
    ├── bug_b/
    │   ├── index.html
    │   ├── style.css
    │   └── app.js
    ├── NOTES.md
    ├── error_404.png
    └── error_offline.png
```

Nothing else goes in your folder, and never change another student's folder.

The tasks are in [EXERCISES.md](../EXERCISES.md) and the submission steps in [SUBMITTING.md](../SUBMITTING.md).
